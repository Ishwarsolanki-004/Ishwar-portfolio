LEAD CASE

FlyRank Content Refresh / Search Intelligence ML Project

A machine learning project using content performance data to identify potentially declining content and prioritize items for review.

01 — PROBLEM

Identifying content that may need attention

The project focuses on identifying content items with an observed declining label and producing a ranked priority list that can support content-review decisions.

02 — APPROACH

Start simple, validate honestly

The modeling work used a client-grouped train/test split so that clients in the training data did not overlap with clients in the test data.

Logistic Regression was selected as a readable baseline model for the supervised learning problem. During model inspection, potentially problematic label-derived signals were checked and removed before training the clean model.

03 — RESULTS & EVIDENCE

Clean Logistic Regression

0.65 Precision@20
0.70 Precision@50
3,419 Test rows

The test split contained 25 training clients and 7 test clients, with zero client overlap.

04 — ERROR ANALYSIS

Reading the model's mistakes

The clean model produced 964 false positives and 370 false negatives on the test set. Three inspected cases showed that some content items have mixed signals, making them difficult to classify cleanly.

False positive

A high-impression item with a page-1 position received a high declining score despite having a non-declining label.

False positive

An item with weak impressions, engagement, and search position resembled patterns associated with decline.

False negative

A genuinely declining item received a score of 0.4998, showing uncertainty around the classification threshold.
