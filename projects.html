Lead Case · Content Refresh / Search Intelligence

FlyRank ML Project

A machine learning project that uses content and search performance data to identify items that may be declining, producing a ranked priority list to support content-review decisions.

01Problem

Identifying content that may need attention

The project focuses on identifying content items with an observed declining label, and producing a ranked priority list that supports content-review decisions rather than making the call outright.

02Approach

Start simple, validate honestly

The modeling used a client-grouped train/test split, so clients present in training never appeared in the test set — avoiding an easy but misleading source of overlap.

Logistic Regression was chosen as a readable baseline model for the supervised classification problem. During model inspection, potentially problematic label-derived signals were identified and removed before training the final, "clean" model.

04Error Analysis

Reading the model's mistakes

The clean model produced 964 false positives and 370 false negatives on the test set. Inspecting individual cases showed that some content items carry mixed signals, making them genuinely difficult to classify cleanly.

False Positive

A high-impression item with a page-1 search position received a high declining score, despite carrying a non-declining label.

False Positive

An item with weak impressions, engagement, and search position resembled patterns typically associated with decline.

False Negative

A genuinely declining item scored 0.4998 — right at the classification threshold, illustrating the model's uncertainty in borderline cases.
